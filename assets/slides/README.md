# Slides del curso

Coloca aquí los PDF de cada clase y referencia la ruta en el front matter de la clase:

```yaml
slides: /assets/slides/01-contenedores.pdf
```

Recomendaciones:

- Exporta a PDF y comprímelo. Mantén cada archivo por debajo de 25 MB; GitHub Pages no sirve Git LFS.
- Nombra los archivos igual que el archivo de la clase en `_lectures/` para encontrarlos rápido.
- Si prefieres Google Slides, usa Archivo, Publicar en la web, Insertar, y pega la URL del `src` del iframe en el campo `slides`.
